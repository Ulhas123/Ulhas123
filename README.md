#### 🤖 [CentraOperator](https://github.com/Ulhas123/Central)
*Autonomous enterprise operator for finance & accounts payable*

Turns plain-English directives (e.g. *"Process Acme invoice #2041 and reconcile against PO"*) into completed, audited ERP transactions.

- **Deterministic policy gates:** hard programmatic controls enforce financial thresholds and company SOPs outside the model's control.
- **Resumable LangGraph execution:** checkpointed state supports pausing and human-in-the-loop escalation.
- **Independent verification:** outcomes are confirmed through an isolated database read path, not browser UI state, and benchmarked against simulated faults (session drops, CSRF shifts, adversarial interstitial banners).

`Python` • `LangGraph` • `Node.js` • `FastAPI` • `Eval Suite`

### ⚡ High-Scale Machine Learning & Computer Vision

<table>
<tr>
<td width="50%" valign="top">

#### 🔍 [Amazon ML Challenge 2026](https://github.com/Ulhas123/Amazon-ML-Challenge-2026)
*Business entity resolution across 24.2M records*

Matches records across multi-source enterprise business registries under strict real-world memory and CPU limits.

- **Precision-first optimization:** tuned for Macro-F0.5, a precision-weighted metric, to penalize false-positive entity merges.
- **Linear-time candidate blocking:** custom blocking strategies and inverted indices cut pair comparisons by 99.8% before vector scoring.
- **Memory-constrained design:** a chunked pipeline that runs within 16 GB RAM and 14 CPU cores on Windows.

`Python` • `scikit-learn` • `Pandas` • `NumPy` • `Entity Resolution`

**[View repository →](https://github.com/Ulhas123/Amazon-ML-Challenge-2026)**

</td>
<td width="50%" valign="top">

#### 🖐️ [Real-Time Hand & Finger Tracker](https://github.com/Ulhas123/Hand)
*Computer vision kinematics with a live telemetry HUD*

A webcam system that computes 21 3D hand landmarks, classifies each finger's state, and renders live analytics on a high-FPS video stream.

- **Geometric finger kinematics:** deterministic vector logic over MCP, PIP, and TIP angles for per-finger state classification.
- **Fingertip smoothing:** an exponential moving average removes jitter from the index pointer for fluid gesture tracking.
- **Telemetry HUD:** on-screen FPS, hand count, gesture IDs, and active-finger diagnostics.

`Python` • `OpenCV` • `MediaPipe` • `NumPy` • `PyTest`

**[View repository →](https://github.com/Ulhas123/Hand)**
